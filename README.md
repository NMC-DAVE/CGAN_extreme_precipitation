# CGAN_extreme_precipitation
Code for paper "Post-processing for 24-hour advanced forecasting of extreme precipitation using deep learning generative models"


Codes: Implementation codes for this study, including data preprocessing, dataloading, and prediction modules.

Model-lt09: model of lead-time 09h, please download from https://zenodo.org/records/15314237

sample-data: Sample dataset generated from operational historical back-calculation.

Notice:
Specific code segments were adapted and enhanced from Rasp's open-source framework (https://github.com/raspstephan/nwp-downscale), with modifications tailored to meet the requirements of post-processing for 24-hour extreme precipitation forecasting using deep learning generative models in central and eastern China.
